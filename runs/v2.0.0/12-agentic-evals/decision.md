# Decisión F07

Se adopta un runner declarativo local basado en fixtures JSON y comparación
de campos esperados. Es reversible, barato y permite que una futura captura
de observaciones reales conserve el mismo formato. No se agregan dependencias
ni servicios, no se toca F01–F06 y no se inicia F08. La evidencia vigente es
`eval-results.jsonl` y el schema asociado.
