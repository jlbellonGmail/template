# Spec T01

## Propósito

Normalizar las fuentes documentales y la identidad física de unidades v2.

## Criterios de aceptación

- CONSTITUTION es la única fuente activa de principios.
- ROADMAP distingue activo, transversal e histórico y conserva F01/F02 `[x]` y F03 `[ ]`.
- STATUS es breve, humano y enlaza este SUMMARY.
- runs se clasifican por versión sin duplicación.
- scripts soportan `-Version` para proyectar F03 sin iniciarla.
- la evidencia histórica y la compatibilidad legacy se preservan.
