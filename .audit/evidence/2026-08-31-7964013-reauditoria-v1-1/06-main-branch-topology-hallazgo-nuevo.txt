Impacto verificado sobre la adopcion: TEMPLATE.md lista "Use this
template" como mecanismo de reutilizacion explicitamente soportado. El
mecanismo "Use this template" de GitHub copia por defecto unicamente la
rama default del repositorio origen (salvo que el usuario marque
"Include all branches"). La rama default de este repositorio es
`develop`, no `main`. Un consumidor nuevo que use ese mecanismo
recibiria un repositorio SIN rama `main`, exactamente el mismo estado
que este repositorio tiene hoy -- contradiciendo el flujo de
"Setup manual" de AGENTS.md, que presupone "hacer el primer push de
`main` y `develop`" como si `main` ya existiera para pushear.

docs.yml (`on: push: branches: [main], paths: ["docs/**",
"mkdocs.yml"]`) no puede dispararse en el estado actual del
repositorio porque su unica condicion de disparo (push a `main`) no
tiene una rama real a la cual aplicarse. Combinado con GitHub Pages sin
configurar, la capacidad "publicar el sitio MkDocs a GitHub Pages",
descrita en AGENTS.md seccion "CI/CD" como parte de la infraestructura
actual del proyecto, no es funcional en el estado auditado ni puede
llegar a disparar sin una intervencion humana no documentada como paso
obligatorio (main no aparece en la lista de "Setup manual").
